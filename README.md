# Terra Eletrônica - Site Oficial

Site oficial da Terra Eletrônica redesenhado com tecnologias modernas e foco em acessibilidade.

## 🌟 Sobre o Projeto

A Terra Eletrônica é uma empresa brasileira especializada em produtos de tecnologia assistiva, desenvolvendo soluções que promovem inclusão digital e social para pessoas com deficiência.

**Slogan:** "Produtos Especiais para Pessoas Especiais"

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica e acessível
- **CSS3** - Design moderno com Grid/Flexbox e responsividade
- **JavaScript ES6+** - Interatividade e funcionalidades avançadas
- **AOS** - Animações suaves ao scroll
- **VLibras** - Tradução para Libras
- **Font Awesome** - Ícones profissionais
- **Google Fonts** - Tipografia moderna

## 📱 Características

### ✅ Design Moderno
- Layout responsivo mobile-first
- Animações suaves e transições fluidas
- Sistema de cores profissional
- Tipografia otimizada para legibilidade

### ♿ Acessibilidade
- Integração com VLibras para Libras
- Navegação por teclado
- Alto contraste
- Suporte a leitores de tela
- Textos alternativos em imagens

### 🚀 Performance
- Código otimizado
- Imagens comprimidas
- CSS e JS minificados
- Lazy loading
- Service Worker (PWA ready)

## 🎯 Produtos Especiais

### 🎵 Instrumentos NET-MIDI-T.A.
Sistema de instrumentos musicais wireless para musicoterapia:
- **BIG_KBD_25** - Teclado com 25 teclas grandes
- **BOARD_SOUND_12** - Placa retangular com 12 regiões coloridas
- **GIRO_SOUND_09** - Tabuleiro redondo com 09 regiões
- **MUSICAL_BEAM_05** - Sensores laser de distância

### 🖱️ Mouses Especiais
- **Mouse Plus** - Mouse adaptado com acionadores
- **Big Ball Mouse FDAT** - Esfera gigante com filtro anti-tremor
- **Roller Mouse** - Controle por roletes com teclas coloridas

### 🔍 Lupas Eletrônicas
- **Imira_10.cor** - Até 22 modelos de vídeo com efeito 3D
- **Lupa Bolinha** - USB com 56 modos de vídeo
- **Lupa Office** - Manual integrada portátil

### ⌨️ Teclados Especiais
- **Colmeia para Teclado** - Acrílico transparente

Soluções para facilitar comunicação e expressão

## 🚀 Deploy

Este site está configurado para ser hospedado no **GitHub Pages**:

2. Ative o GitHub Pages nas configurações do repositório
3. O site estará disponível em: `https://[usuario].github.io/[repositorio]`
