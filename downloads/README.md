# Downloads - Terra Eletrônica

Esta pasta contém os arquivos de download dos softwares da Terra Eletrônica.

## Arquivos Disponíveis

### 🖥️ Lupa Bolinha (Windows)
- **Arquivo:** `LupaBolinha.zip`
- **Tamanho:** ~153 MB
- **Descrição:** Software de lupa eletrônica para Windows
- **Características:**
  - Ampliação de 2x a 32x
  - Diversos filtros de cor
  - Interface simples e intuitiva
  - Compatível com Windows

### 📱 MobiLupa (Android)
- **Arquivo:** `MobiLupa.apk`
- **Tamanho:** ~5 MB
- **Descrição:** Aplicativo de lupa para Android
- **Características:**
  - Usa a câmera do dispositivo
  - Zoom digital e foco automático
  - Lanterna integrada
  - Interface otimizada para mobile

Se você está configurando o ambiente de desenvolvimento:

1. Obtenha os arquivos de download do servidor de produção
2. Coloque-os nesta pasta (`downloads/`)
3. Os arquivos serão ignorados pelo Git conforme configurado no `.gitignore`
